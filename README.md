# Liang Chen / 陈亮

Personal website of Liang Chen, co-founder of SiliconProspect AI.

**Live:** https://wanmo8908.github.io/

A buildless HTML, CSS and JavaScript website with an interactive Canvas neural field. No tracking, external fonts or runtime dependencies.

## Preview

Serve this directory with any static HTTP server, then open `index.html` through that server.

## Controls

- Switch the three perspectives in the Neural Observatory.
- Move the pointer over the neural field to explore it.
- Use the motion toggle to pause animation.
- Press Ctrl+K / Command+K for quick navigation.
- The page respects the system's reduced-motion preference.

## GitHub Pages

In repository Settings → Pages, select **Deploy from a branch**, then **main** and **/ (root)**. The `.nojekyll` file keeps this a plain static site.
